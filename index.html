About Mini Games Hub

Mini Games Hub is a web-based collection of interactive games developed using HTML, CSS, and JavaScript.

The project demonstrates fundamental web development concepts through engaging gameplay, user interaction, game-state management, and modular programming.

Developed as part of the Bachelor of Computer Applications (BCA) academic curriculum.
